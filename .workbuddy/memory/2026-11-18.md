# 2026-11-18

## 新增 PDF 转图片功能（MVP）

- 产品约定：转换完只导出图片文件夹，不自动导入打码流程；默认 200 DPI + PNG。
- 依赖选择 pypdfium2（免外部 Poppler）；`requirements.txt` 与 `run.bat` 依赖检查同步更新。PyMuPDF 因 AGPL/商业双授权未采用。
- 新增 `masai/core/pdf_convert.py`：渲染 PDF 页为 `原名_p001.png`，支持页码表达式、JPEG 质量、DPI 限制、同名 PDF 用父目录名消歧、逐页取消与失败报告；不依赖 Qt。
- 新增 `masai/ui/pdf_dialog.py` 与 `masai/ui/pdf_worker.py`：对话框复用主题/校验风格，后台 QThread 复用主窗口进度条与取消。
- `masai/ui/main_window.py` 增加工具栏「PDF 转图片」入口、拖入 PDF 直接打开转换对话框，以及转换完成/取消/失败的状态处理；转换不会改动当前图片会话。
- 测试：新增 `tests/test_pdf_convert.py`、`tests/test_pdf_dialog.py` 与 GUI 冒烟断言；全套 61 passed。
- 注意：本环境 `pip install -r requirements.txt` 会因沙箱 safe-delete 守卫在替换 PySide6 文件时报错，但依赖已可用；跑 pytest 时需用 `--basetemp="$(mktemp -d)"` 避开 pytest 清理旧临时目录触发同一守卫。
