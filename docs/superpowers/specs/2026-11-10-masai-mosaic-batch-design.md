# MaSai — 批量图片同区域马赛克工具 设计稿

日期：2026-11-10
状态：已确认，进入实现

## 目标

给一批"内容相同、尺寸可能不同"的图片，在同一相对位置打像素化马赛克。
文件夹导入、文件夹导出、多区域、保持原文件名与原格式。

非目标（明确不做）：递归子文件夹、记住上次配置、前后对比视图、圆形/自由多边形遮罩、涂色遮挡。

## 形态

Windows 桌面程序，Python 3.13 + PySide6 6.9 + Pillow 12。
`python -m masai` 启动，`run.bat` 双击运行。

## 核心模型

区域坐标以图像宽高的 0~1 相对比例存储（`Region(x, y, w, h)`）。
块大小以"相对图像宽度"的比例存储（`MosaicPlan.block_fraction`）。

由此，任意尺寸的图片都能按自身宽高等比换算像素框，块大小同步缩放，
视觉上保持一致。若某图宽高比与参考图相差超过 2%，列表中标黄提示
（可能是被裁剪过，套用后会错位），但不阻止处理。

## 马赛克算法

对每张图：

1. `ImageOps.exif_transpose` 归正方向。
2. 所有区域取**并集**成一张蒙版（区域可重叠）。
3. 块网格以**图像原点**为基准全局对齐，全图共用同一套网格。
4. 每个单元格只用**蒙版内**的原图像素求均值（边缘不满一块的格只统计框内部分），
   再回填到该单元格内的蒙版像素。
5. 只改写蒙版内的像素，区域外**逐字节不变**（隐私打码的硬要求）。
6. 均值全部取自原图，因此重叠区域不级联，重复处理结果不变（幂等）。

等价伪码：

```
mask = union(rects)
for cell in grid_cells:            # 网格与图像原点对齐
    out[cell & mask] = mean(src[cell & mask])
```

两条容易写错、已用测试锁死的性质：

- **不外溢**：早期版本把区域向外扩到整块再填充，最多会把马赛克推到框外 15 px。
  现在的实现严格裁剪到蒙版内，1 px 的区域就是 no-op。
- **边缘格不被污染**：不满一块的边缘格只统计框内像素，不会把框外的白色背景
  平均进来，避免出现"框内发白"的方块。

实现按「网格行带」逐条累加，峰值内存只与单条行带相关（数百 KB），
因此 6000×4000 的图也只需约 130 ms，不会构造整图浮点副本。

## 导出

- 输出目录默认 `原文件夹名_mosaic`，也可自选。
- 保持原文件名与原格式（JPEG 质量 95、4:4:4，保留 EXIF 并把方向标记置 1；
  PNG 保留透明通道与 ICC；WebP quality 95；BMP/TIFF 原样）。
- 动图 GIF 跳过并计入失败清单；损坏文件同样跳过并报告。
- 4 线程并行，支持中途取消（当前张处理完后停止）。

## 界面

```
┌──────────┬──────────────────────────────┬──────────┐
│ 导入文件夹│                              │ 区域列表  │
│ 图片列表  │      画布（参考图）            │  #1 240×80│
│ 128 张    │   拖拽框选 / 实时马赛克         │  #2 120×60│
│ ▸ a.jpg  │   滚轮缩放 / 中键平移           │ 块大小 ──●│
└──────────┴──────────────────────────────┴──────────┘
│ 进度条 ──────────  状态文本           [取消] [导出]  │
```

- 拖入文件夹或按钮导入；点击列表任一张即切换参考图。
- 画布上拖拽新增区域；选中后可整体拖动、拖 4 个角控制点改大小、Del 删除。
- 画布实时显示马赛克结果（拖动过程中只显示框，松手后出效果，保证流畅）。

## 代码结构

```
masai/__main__.py          python -m masai
masai/app.py               QApplication 入口
masai/ui/main_window.py    主窗口与业务编排
masai/ui/image_canvas.py   画布、区域图元、框选交互、预览
masai/ui/batch_worker.py   QThread 包装 core.run_batch
masai/core/regions.py      归一化区域模型与换算
masai/core/mosaic.py       马赛克算法
masai/core/pipeline.py     单图处理与保存、格式/EXIF 规则
masai/core/batch.py        批量调度、进度、取消
tests/                     坐标往返、块对齐、区域外不变、比例套用、导出格式
```

## 测试

pytest 覆盖纯核心逻辑（不依赖 Qt）：

- 归一化坐标往返误差 ≤ 1px；越界坐标被裁剪。
- 块网格对齐；重叠区域不级联；灰度/RGBA 模式正确。
- 区域外像素与输入逐字节相同。
- 不同尺寸图片按比例套用同一区域。
- 导出保持文件名、格式、尺寸；EXIF 方向被归正。

界面部分用 offscreen 平台做实例化冒烟测试。
